# slide-it kit

Copy-in snippets for single-file HTML artifacts. Each is a `<style>` + markup + an IIFE `<script>`; paste the whole file where the component goes. Paste `theme-toggle.html` once, first (it holds the token block; the names are in `TOKENS.md`); every other file carries a zero-specificity fallback token block, so it also runs alone and a real token block always wins. Every script initialises each of its roots once (`data-si-ready`) and generates its own ids, so a second instance needs no id changes: copy only the root element, keep one `<style>` and one `<script>`. The first line of every file (a `<meta charset>` + viewport pair) is only for running the file alone: drop it when pasting. Sample content is marked "Sample" and must be replaced. The finished pages in `../examples/` show how these are put together; start from one of them.

- **screens.html**: The page scaffold: a stack of screens on a normally scrolling page, each heading a small question (`data-label` + `.si-q`) over its one-sentence answer in an `<hgroup>`, with a collapsed `<details class="si-more">` under the interaction for that screen's deeper story; the questions are listed at the right edge, always visible (faint until you point at them), on a wide desktop (from 1200px; marks that open a panel on hover or Tab from 900px) and a sticky tab strip on a phone (theme switch in all), plus a "Next: question" link at each screen's foot and arrow keys. Every page starts here.
- **theme-toggle.html**: the token block (light on `:root`, dark under the guarded media query and `[data-theme="dark"]`) plus a sun/moon button that saves `si.theme`; for every page; once per page, nothing to rename (extra `.si-theme-toggle` buttons all work).
- **figure-iso.html**: an isometric figure of a real object (phone, server rack, desk) with a segmented control that moves a packet through it, a live readout and an aria-live caption; only when a physical thing itself is the page's subject (see `../figures.md`); paste its style and kit script once, then only the figure's markup and script; see `figures/README.md`.
