# Developer & technology

Looks like Stripe docs, Linear, Vercel. For APIs, system architecture, infra and cloud cost, CLIs and SDKs, security reviews, AI/ML tooling, build-vs-buy for engineers, postmortems and stack choices.

**Colour:** Committed violet on cool graphite, cyan for data in motion. Dark is the showcase (design it first); light is crisp.

**Light** `--bg:#f6f7fb;--surface:#fff;--fg:#0b1020;--muted:#4b5675;--line:#dde1ee;--accent:#5546e8;--accent-fg:#fff;--good:#0b7a4f;--warn:#94570a;--bad:#c0264b;--accent-2:#0e7490;--tint:#ece9ff;`

**Dark** `--bg:#090c16;--surface:#11162a;--fg:#e8ebf7;--muted:#97a2c3;--line:#232b47;--accent:#a094ff;--accent-fg:#0a0720;--good:#3ddc97;--warn:#f0b03a;--bad:#ff6b8a;--accent-2:#22d3ee;--tint:#1a1740;`

**Type:** Geist 600/700 display (tight, -0.02em) + Geist 400/500 body + Geist Mono for code, ids, paths and numbers only. `Geist:wght@400;500;600;700` `Geist+Mono:wght@400;500`. Fallback: sans `system-ui,-apple-system,"Segoe UI",Roboto,sans-serif`, mono `ui-monospace,"SF Mono",Menlo,Consolas,monospace`.

**Shape:** radius 8, 1px `--line` borders, dense 8px rhythm, small mono labels.


**Motion:** crisp and quick (`--dur-fast`/`--dur`), packets and caret only.

Steer clear of: matrix-green hacker costume, neon glow, gradient text, sparkle "AI" icons, a purple-blue gradient hero as the only idea, a terminal window that is decoration.
